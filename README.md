One original funny line about everyday life, written by a program to `/output/entry.txt` for make.fun's "One-Line Laugh Sprint" bounty.

The line:

> I put my phone on Do Not Disturb for some peace and quiet, then spent the whole evening disturbing myself.

The joke is a small paradox everyone with a phone knows: the silencer isn't the phone, it's you. The twist lands on the very last word, and the line reads well aloud with nothing spare.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (creating the directory if needed) and prints the character count. The entry is 106 characters of UTF-8 text, inside the 1–200 character gate.
